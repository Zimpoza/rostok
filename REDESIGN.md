# Росток 4.0 — план внедрения

> Исполнение: в этой сессии, с проверкой поведения перед публикацией.

**Цель:** выполнить согласованную переработку трёх экранов, сохранив существующий прогресс и курсы.
**Архитектура:** статическое приложение без новых зависимостей в продукте. Существующие app.js, index.html и sw.js; дополнительные поля состояния совместимы со старыми копиями.
**Стек:** HTML, CSS, JavaScript. Тесты интерфейса — Node и jsdom/Playwright отдельно от продукта.
**Спецификация:** согласованный пользователем объём в этом диалоге; детали ниже.

## Требования
- Сегодня: заметно новая композиция, продолжение последнего незавершённого урока, три ближайших незавершённых дела, остальные дела в раскрываемом списке, итог дня и режим дня.
- Обучение: сетка направлений, прогресс курса; урок с индикатором и этапами теория/практика/результат, объяснение ответа по материалу урока, повтор только ошибок, следующий доступный урок или экзамен.
- Рост: выбор недели, сравнение завершённых минут/дел с прошлой неделей; слабые темы по упражнениям и экзаменам, история попыток, прежние календарь, награды и итоги.
- Прогресс: прежний ключ dnevnik-state и все id сохранены; резервный снимок перед перезаписью, восстановление повреждённого основного состояния, видимое предупреждение при ошибке записи, проверка импорта и подтверждение замены.
- Не добавлять выдуманные предметные объяснения: использовать правило и примеры соответствующего урока.
- Версия 4.0 согласована в приложении, скриптах и сервис-воркере; кеши только с префиксом rostok, обновление уже открытого окна уведомлением.

## Проверки, определяющие приёмку
Повреждённый JSON и отказ localStorage не должны стирать данные. Старый файл копии должен импортироваться, чужой JSON — отклоняться. Повтор ошибок не должен улучшать исходную оценку первой попытки. Неделя 1 не должна сравниваться с выдуманной неделей 0. На ширинах 390/1280 и в тёмной теме не должно быть горизонтального переполнения.

## Проверка и решения

Реализовано на существующем стеке в отдельной ветке. Утверждённый объём взят из диалога пользователя. Незаконченный урок и указатель продолжения остаются на устройстве: синхронизация их по отдельным полям смешивала разные уроки. Старая схема дневника и все id сохранены.

Независимая проверка выявила четыре существенные ошибки (пустые контейнеры при слиянии, вложенные данные экзаменов, смешивание сессий, некорректные оценки и повтор). Все воспроизведены тестами и исправлены. Устаревшие результаты урока больше не скрывают более свежие ошибки экзамена. Добавлена защита ключей объектов при импорте.

Ограничения: настоящая синхронизация с токеном GitHub и iPhone Safari не проверялись. Наследуемая гонка одновременного изменения Gist на двух устройствах остаётся; интерфейс сообщает об этом. Выход: предварительный запрос на добавление в основной репозиторий, принятие владельцем.
