# HANDOFF: «Росток» (репозиторий machokhulios-hub/rostok)

Записка для нового диалога. Прочитай её первой, потом делай правки. Обновлено: 27.10.2026, версия 4.2.

## Что это
Личное приложение Александра для учёбы и роста (телефон и компьютер). Статический сайт на GitHub Pages: https://machokhulios-hub.github.io/rostok/?v=N. Бэкенда нет. Прогресс хранится в localStorage браузера (ключ `dnevnik-state`), у каждого устройства и окна он свой. В «Итогах» есть кнопки копии в файл и восстановления.

## Как устроен код
- `index.html` подключает `plan.js`, `courses.js`, `app.js` с `?v=N`; цвета разделов заданы в `:root` как `--c-<cat>`.
- `courses.js` — все курсы. Курс типа `path` = список шагов (урок или экзамен). Урок: `id, t, plan, theory{rule, ex[[a,b]], tip}, ex[5 вопросов choice]`. Экзамен: `exam:true, covers[], pass:0.8, q[]`. В вопросе `choice` ПЕРВЫЙ вариант всегда правильный, приложение перемешивает. Есть ещё типы `input` и `order`. **id уроков и экзаменов менять нельзя**, иначе пропадёт прогресс.
- `app.js`: версия в `APP_VERSION`, список разделов в `CATS`, подсчёт серии в `streak()`.
- `sw.js` — офлайн-кеш, сначала сеть. Имя кеша `rostok-vX-Y`.

## Как выпускать версию (всегда все четыре шага)
1. `APP_VERSION` в `app.js`.
2. `?v=N` в трёх тегах script в `index.html`.
3. `?v=N` в списке файлов и имя кеша `rostok-vX-Y` в `sw.js`.
4. Проверка: `node --check courses.js app.js`, открыть в браузере на ширине 390 и 1280, потом commit и push в main.

Синхронизация: при запуске, при возврате в приложение (раз в минуту), через 6 с после изменения, по кнопке. Не атомарно: если два устройства синхронизируются в одну секунду, возможна потеря одной правки. Проверено только на макете GitHub API (jsdom, два «устройства»); с настоящим GitHub (CORS, токен) и на экране 390/1280 НЕ проверено.

## v4.0: согласованная переработка
- «Сегодня»: новая композиция, карточка продолжения последнего урока, три ближайших незавершённых дела, остальной план в раскрывающемся списке, ритм и режим дня. Три прежних раздела сохранены. Десктоп: боковое меню; телефон: нижнее.
- «Обучение»: сетка направлений, этапы урока, сохранение ответов после перезагрузки, объяснение из правила и примеров урока, повтор только ошибок без повышения первой оценки, экран завершения и следующий урок/экзамен. Повтор ошибок экзамена не изменяет оценку и число попыток.
- «Мой рост»: выбор недели, сравнение выполненных минут/дел/уроков с предыдущей, слабые темы по свежим попыткам и история экзаменов. Время по делам — плановая длительность отмеченных задач, не таймер. Награды, календарь и копии остались.
- Состояние: прежний ключ dnevnik-state, новые practice/session/lastStudy. Перед записью сохраняется предыдущий корректный JSON в dnevnik-state-backup. Повреждённый основной JSON восстанавливается из снимка; без снимка не перезаписывается, можно скачать оригинал. Импорт проверяется и требует подтверждения замены. При ошибке записи постоянное предупреждение, синхронизация приостановлена.
- session и lastStudy — только на текущем устройстве, в Gist не отправляются. Копии в файл их содержат. Токен по-прежнему отдельно и в копию не попадает. Слияние Gist сохраняет совместимость с пустыми контейнерами старых данных.
- Офлайн: кеш rostok-v4-0, только свои кеши удаляются; HTML выдаётся запасным ответом только при навигации; открытое окно сообщает о новой версии.
- Проверка: npm ci && npm test (Node 24+), 28 проверок. Chromium: ширины 390/1280, светлая/тёмная темы, все три экрана, урок и сохранение ответов, без ошибок JS и горизонтального переполнения.
