# HANDOFF: «Росток» (репозиторий machokhulios-hub/rostok)

Записка для нового диалога. Прочитай её первой, потом делай правки. Обновлено: 26.10.2026, версия 3.2.

## Что это
Личное приложение Александра для учёбы и роста (телефон и компьютер). Статический сайт на GitHub Pages: https://machokhulios-hub.github.io/rostok/?v=N. Бэкенда нет. Прогресс хранится в localStorage браузера (ключ `dnevnik-state`), у каждого устройства и окна он свой. В «Итогах» есть кнопки копии в файл и восстановления.

## Как устроен код
- `index.html` подключает `plan.js`, `courses.js`, `app.js` с `?v=N`; цвета разделов заданы в `:root` как `--c-<cat>`.
- `courses.js` — все курсы. Курс типа `path` = список шагов (урок или экзамен). Урок: `id, t, plan, theory{rule, ex[[a,b]], tip}, ex[5 вопросов choice]`. Экзамен: `exam:true, covers[], pass:0.8, q[]`. В вопросе `choice` ПЕРВЫЙ вариант всегда правильный, приложение перемешивает. Есть ещё типы `input` и `order`. **id уроков и экзаменов менять нельзя**, иначе пропадёт прогресс.
- `app.js`: версия в `APP_VERSION`, список разделов в `CATS`, подсчёт серии в `streak()`.
- `sw.js` — офлайн-кеш, сначала сеть. Имя кеша `rostok-vX-Y`.

## Как выпускать версию (всегда все четыре шага)
1. `APP_VERSION` в `app.js`.
2. `?v=N` в трёх тегах script в `index.html`.
3. `?v=N` в списке файлов и имя кеша `rostok-vX-Y` в `sw.js`.
4. Проверка: `node --check courses.js app.js`, открыть в браузере на ширине 390 и 1280, потом commit и push в main.

Шаги pc1–pc6 (Пушкин, Лермонтов, Блок, Есенин, Маяковский) имеют поле `wiki {a,q,m}`: приложение ищет страницу через API ru.wikisource.org (`origin=*`), берёт `.poem` и показывает текст через textContent; при неудаче кнопка «Найти в Викитеке». Шаги pc7–pc10 (Шекспир, Киплинг, По, Фрост) имеют поле `link`: только ссылка на en.wikisource (переводы могут быть под авторским правом). Проверено только на макете ответа в jsdom; на настоящей Викитеке (CORS, точность поиска) и на экране 390/1280 НЕ проверено.
- v3.2: синхронизация через секретный Gist (карточка в «Итогах» под резервной копией). Токен classic с правом `gist` вставляется в приложение и лежит только в localStorage под ключом `rostok-sync` (там же снимок `base` — состояние после прошлой синхронизации); в файл копии и в Gist он не попадает. Gist ищется по файлу `rostok-state.json`, на втором устройстве нужен тот же токен. Слияние трёхстороннее (здесь / в Gist / base): снятая отметка не воскресает, при конфликте число берётся большее, текст длиннее. Перед включением предлагается файл копии. Синхронизация: при запуске, при возврате в приложение (раз в минуту), через 6 с после изменения, по кнопке. Не атомарно: если два устройства синхронизируются в одну секунду, возможна потеря одной правки. Проверено только на макете GitHub API (jsdom, два «устройства»); с настоящим GitHub (CORS, токен) и на экране 390/1280 НЕ проверено.
