# HANDOFF: «Росток» (репозиторий machokhulios-hub/rostok)

Записка для нового диалога. Прочитай её первой, потом делай правки. Обновлено: 26.10.2026, версия 3.0.

## Что это
Личное приложение Александра для учёбы и роста (телефон и компьютер). Статический сайт на GitHub Pages: https://machokhulios-hub.github.io/rostok/?v=N. Бэкенда нет. Прогресс хранится в localStorage браузера (ключ `dnevnik-state`), у каждого устройства и окна он свой. В «Итогах» есть кнопки копии в файл и восстановления.

## Как устроен код
- `index.html` подключает `plan.js`, `courses.js`, `app.js` с `?v=N`; цвета разделов заданы в `:root` как `--c-<cat>`.
- `courses.js` — все курсы. Курс типа `path` = список шагов (урок или экзамен). Урок: `id, t, plan, theory{rule, ex[[a,b]], tip}, ex[5 вопросов choice]`. Экзамен: `exam:true, covers[], pass:0.8, q[]`. В вопросе `choice` ПЕРВЫЙ вариант всегда правильный, приложение перемешивает. Есть ещё типы `input` и `order`. **id уроков и экзаменов менять нельзя**, иначе пропадёт прогресс.
- `app.js`: версия в `APP_VERSION`, список разделов в `CATS`, подсчёт серии в `streak()`.
- `sw.js` — офлайн-кеш, сначала сеть. Имя кеша `rostok-vX-Y`.

## Как выпускать версию (всегда все четыре шага)
1. `APP_VERSION` в `app.js`.
2. `?v=N` в трёх тегах script в `index.html`.
3. `?v=N` в списке файлов и имя кеша `rostok-vX-Y` в `sw.js`.
4. Проверка: `node --check courses.js app.js`, открыть в браузере на ширине 390 и 1280, потом commit и push в main.

## Правила работы с Александром
- Пишет по-русски, часто с телефона. Отвечать коротко: сначала результат, потом пояснение. Один лучший вариант, а не несколько. Термины пояснять одной фразой. Обращаться на «ты».
- Новый дизайн сначала показать макетом, внедрять после слова «ставь».
- Не переписывать то, о чём не просили (он экономит лимиты).
- В конце: что сделано, какая версия, ссылка с `?v=N`, что проверить не удалось (например iPhone). Не писать «готово», пока не убедился.
- Не выдумывать факты. Правила русского, английского, стихов и данные для «Тяги» писались по памяти без сверки со справочником: честно об этом говорить.
- Рабочие данные для сайта «Тяга» (локомотивные бригады) только из проверенных источников.
- room78.net: ничего не менять на боевом сайте без резервной копии и его «ставь».
